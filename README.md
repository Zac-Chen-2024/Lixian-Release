# 理弦 · 下载

理弦是一个学吉他的 Android App：不背指法，在琴上自己发现指板和听觉的规则。这个仓库只放安装包。

**[下载最新版](https://github.com/Zac-Chen-2024/Lixian-Release/releases/latest)**：打开后点 `lixian-数字.apk`，下载完在手机上安装。

装好之后不用再回这里。App 打开时会自己检查新版本，首页提示后点一下就能下载、安装，练习进度都会保留。

## 这个仓库怎么来的

理弦的源码在私有仓库里。每次发布新版，那边的 CI 把签好名的 APK 推到这里的 `drop` 分支，这里的 workflow 再把它发成 Release。App 读的就是这里最新的 Release。

- 每个 APK 都用同一个签名，所以能覆盖安装。
- 版本号后面的数字是构建号，越大越新。
